# Privacy principles

NexKey handles highly sensitive input. Privacy is a core product requirement.

- Basic typing must work offline.
- Do not log or upload typed text, passwords, payment details or clipboard contents.
- Do not transmit text to remote AI services unless the user deliberately invokes the feature and receives clear disclosure.
- Prefer on-device dictionaries and language processing where practical.
- Request only permissions needed for a feature and explain why they are needed.
- Provide clear controls for optional analytics, cloud sync and AI features.
- Keep secrets and signing keys out of the repository.
- Publish a complete privacy policy before public release.

This document records product requirements; it is not a claim that the current scaffold has completed a privacy or security audit.
